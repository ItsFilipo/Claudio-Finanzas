# Aplicación de finanzas

## Habilidades del proyecto (`.claude/skills/`)
- **ponytail**: usar en toda tarea de código; la solución más simple que funcione.
- **impeccable**: usar en todo trabajo de interfaz y diseño frontend.
- **graphify**: usar para entender la estructura del proyecto (requiere `pip install graphifyy` en la sesión).

## Flujo de trabajo
El usuario trabaja solo desde la web y no maneja GitHub.
- Trabajar siempre en la rama borrador de la sesión, con commit y push.
- Unir a `main` solo cuando el usuario lo ordene explícitamente.
